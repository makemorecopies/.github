Software is worth keeping.

We build open-source tools for finding, installing, distributing, and preserving software.

We care about software that is easy to access, easy to keep, and difficult to lose. That means better distribution, better preservation, fewer unnecessary barriers, and infrastructure that does not depend on a single store, service, or download staying online forever.

If something useful disappears because a store closes, a service shuts down, or a download link dies, that's a pretty bad ending.

**Make more copies.**
